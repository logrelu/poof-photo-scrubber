# Voice & Design: Poof 🫧

**Personality:** a tiny friendly ghost-bubble that makes your secrets go *poof*. Playful, never paranoid.

| Thing | Value |
|---|---|
| Name | Poof |
| Icon (Shortcuts glyph/colour) | Sparkles glyph, **Purple** (shortcut colour code in builder) |
| Palette | Bubble lilac `#B9A7FF`, mint `#8CF5D0`, ink `#1B1530`, peach `#FFC2A8` |
| Success copy | "Poof! 🫧 Where & when are gone." |
| Count copy | "Poofed 3 photos. They're none the wiser." |
| Error copy | "Hmm, that one wouldn't poof. Try again?" |
| Peek copy | "This photo was telling on you: 📍 … 🕒 … 📱 …" |
| Never say | "secure", "military-grade", "anonymous" (we promise metadata only) |
